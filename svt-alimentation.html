Exercice 1 : Les groupes d'aliments

Quel groupe d'aliments apporte des protéines ?

Les fruits
Les légumes
Les viandes et poissons
Les pains

Correction

Bonne réponse : Les viandes et poissons

Les protéines sont essentielles pour construire et réparer nos muscles. On les trouve principalement dans la viande, le poisson, les œufs et les produits laitiers. Les fruits et légumes apportent surtout des vitamines, et les pains apportent des glucides (énergie).

Exercice 2 : Les glucides

Quel groupe d'aliments apporte de l'énergie (glucides) ?

Les pains, pâtes et riz
Les viandes
Les légumes
Les produits laitiers

Correction

Bonne réponse : Les pains, pâtes et riz

Les glucides sont la principale source d'énergie pour notre corps. On les trouve dans les féculents (pain, pâtes, riz, pommes de terre), les légumineuses et les produits sucrés. Ils fournissent le carburant nécessaire pour nos activités quotidiennes.

Exercice 3 : Les vitamines

Dans quels aliments trouve-t-on le plus de vitamines ?

Dans la viande
Dans le pain
Dans les fruits et légumes
Dans les produits laitiers

Correction

Bonne réponse : Dans les fruits et légumes

Les fruits et légumes sont les principales sources de vitamines. La vitamine C se trouve dans les agrumes, la vitamine A dans les carottes, etc. Les vitamines sont essentielles pour le bon fonctionnement de l'organisme et renforcent les défenses immunitaires.

Exercice 4 : L'équilibre alimentaire

Qu'est-ce qu'une alimentation équilibrée ?

Manger seulement des légumes
Manger beaucoup de sucre
Varier les groupes d'aliments en quantités adaptées
Sauter des repas

Correction

Bonne réponse : Varier les groupes d'aliments en quantités adaptées

Une alimentation équilibrée consiste à manger de tous les groupes d'aliments (fruits, légumes, protéines, féculents, produits laitiers) dans les bonnes proportions. Cela permet d'apporter tous les nutriments nécessaires au corps.

Exercice 5 : L'hydratation

Combien d'eau faut-il boire par jour environ ?

1 verre
3 verres
1,5 à 2 litres
5 litres

Correction

Bonne réponse : 1,5 à 2 litres

Il est recommandé de boire environ 1,5 à 2 litres d'eau par jour pour rester hydraté. L'eau est essentielle pour le bon fonctionnement du corps : elle transporte les nutriments, élimine les déchets et régule la température.

Exercice 6 : Les glucides

Quel est le rôle principal des glucides ?

Construire les muscles
Fournir de l'énergie
Renforcer les os
Protéger contre les microbes

Correction

Bonne réponse : Fournir de l'énergie

Les glucides (sucres, féculents) sont la principale source d'énergie pour le corps. Ils sont transformés en glucose qui alimente les cellules. Les féculents (pain, pâtes, riz, pommes de terre) sont des glucides complexes qui fournissent de l'énergie durable.

Exercice 7 : Les lipides

Quel est le rôle des lipides (graisses) ?

Uniquement stocker de l'énergie
Stocker de l'énergie et protéger les organes
Fournir des vitamines seulement
Être totalement inutiles

Correction

Bonne réponse : Stocker de l'énergie et protéger les organes

Les lipides sont une réserve d'énergie pour le corps. Ils protègent également les organes (comme le cœur) et participent à la constitution des cellules. Il faut consommer des graisses en quantité raisonnable, en privilégiant les graisses insaturées.

Exercice 8 : Le calcium

Dans quels aliments trouve-t-on du calcium ?

Dans les fruits
Dans les produits laitiers
Dans la viande
Dans le pain

Correction

Bonne réponse : Dans les produits laitiers

Le calcium se trouve principalement dans les produits laitiers (lait, yaourt, fromage). Il est essentiel pour la construction et le maintien des os et des dents. Les enfants et les adolescents en ont particulièrement besoin pour leur croissance.

Exercice 9 : Le sucre

Quels sont les effets d'une consommation excessive de sucre ?

Améliorer la concentration
Augmenter le risque de caries et de diabète
Renforcer les os
Améliorer la digestion

Correction

Bonne réponse : Augmenter le risque de caries et de diabète

Le sucre en excès favorise les caries dentaires et peut augmenter le risque de diabète et d'obésité. Il est recommandé de limiter la consommation de produits sucrés (sodas, bonbons, pâtisseries) et de privilégier le sucre naturel des fruits.

Exercice 10 : Les fibres

Dans quels aliments trouve-t-on des fibres ?

Dans la viande
Dans les produits laitiers
Dans les fruits, légumes et céréales complètes
Dans les œufs

Correction

Bonne réponse : Dans les fruits, légumes et céréales complètes

Les fibres se trouvent dans les aliments d'origine végétale : fruits, légumes, légumineuses, céréales complètes. Elles facilitent le transit intestinal, donnent une sensation de satiété et aident à réguler le taux de sucre dans le sang.
