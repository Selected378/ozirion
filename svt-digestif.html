Exercice 1 : Le système digestif

Quel organe permet d'absorber les nutriments ?

L'estomac
L'intestin grêle
Le foie
Le pancréas

Correction

Bonne réponse : L'intestin grêle

L'intestin grêle est l'organe où les nutriments issus de la digestion passent dans le sang. C'est un long tube très plié qui augmente la surface d'absorption. L'estomac, lui, commence la digestion mais n'absorbe presque pas de nutriments.

Exercice 2 : La respiration

Quel gaz inspirons-nous pour respirer ?

Le dioxyde de carbone
L'oxygène
L'azote
L'hydrogène

Correction

Bonne réponse : L'oxygène

Lorsque nous respirons, nous inspirons de l'oxygène qui est essentiel pour produire de l'énergie dans nos cellules. Nous expirons du dioxyde de carbone, un déchet de cette production d'énergie. Sans oxygène, nos cellules ne peuvent pas fonctionner.

Exercice 3 : Le système circulatoire

Quel organe pompe le sang dans tout le corps ?

Les poumons
Le cœur
Le cerveau
L'estomac

Correction

Bonne réponse : Le cœur

Le cœur est un muscle qui fonctionne comme une pompe. Il contracte rythmiquement pour propulser le sang dans les artères vers tous les organes du corps. Le sang circule en boucle : il part du cœur, va aux poumons pour se charger en oxygène, retourne au cœur, puis est distribué à tout l'organisme.

Exercice 4 : L'élimination des déchets

Quel organe élimine les déchets du sang pour former l'urine ?

Le foie
Les reins
L'estomac
Les poumons

Correction

Bonne réponse : Les reins

Les reins filtrent le sang pour éliminer les déchets et l'excès d'eau. Ils produisent l'urine qui est stockée dans la vessie avant d'être évacuée. Les reins maintiennent également l'équilibre des sels minéraux dans le corps.

Exercice 5 : Le système nerveux

Quel organe commande tout le corps ?

Le cœur
L'estomac
Le cerveau
Les poumons

Correction

Bonne réponse : Le cerveau

Le cerveau est le centre de commande du corps. Il reçoit les informations des sens, les traite et envoie des ordres aux muscles et aux organes. Il contrôle aussi la pensée, la mémoire et les émotions.

Exercice 6 : La digestion des graisses

Quel organe produit la bile pour digérer les graisses ?

Le foie
L'estomac
Le pancréas
L'intestin

Correction

Bonne réponse : Le foie

Le foie produit la bile qui est stockée dans la vésicule biliaire. La bile permet d'émulsionner les graisses pour faciliter leur digestion par les enzymes du pancréas. Sans bile, les graisses ne seraient pas bien digérées.

Exercice 7 : Les alvéoles pulmonaires

Où se passe l'échange des gaz dans les poumons ?

La trachée
Les bronches
Les alvéoles
Le diaphragme

Correction

Bonne réponse : Les alvéoles

Les alvéoles sont de petits sacs situés au bout des bronchioles. C'est là que l'oxygène passe dans le sang et le dioxyde de carbone passe du sang vers l'air. Leur grande surface permet un échange efficace des gaz.

Exercice 8 : Le sang

Quels sont les cellules du sang qui transportent l'oxygène ?

Les globules blancs
Les globules rouges
Les plaquettes
Le plasma

Correction

Bonne réponse : Les globules rouges

Les globules rouges contiennent de l'hémoglobine, une protéine qui se fixe à l'oxygène. Ils transportent l'oxygène des poumons vers tous les organes. Les globules blancs défendent contre les infections et les plaquettes aident à la coagulation.

Exercice 9 : La vessie

Quel organe stocke l'urine avant son évacuation ?

Les reins
L'urètre
La vessie
L'uretère

Correction

Bonne réponse : La vessie

La vessie est un sac musculaire qui stocke l'urine produite par les reins. Quand elle est pleine, le cerveau envoie le signal d'envie d'uriner. L'urine est ensuite évacuée par l'urètre.

Exercice 10 : Les nerfs

Que transportent les nerfs ?

Le sang
Des signaux électriques
L'air
La nourriture

Correction

Bonne réponse : Des signaux électriques

Les nerfs transportent des signaux électriques appelés influx nerveux. Ces signaux permettent au cerveau de communiquer avec toutes les parties du corps. Ils permettent de ressentir, de bouger et de contrôler les organes.
